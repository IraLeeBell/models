# Copilot model catalog

An [as-of-2026-10-06 catalog](models/README.md) of publicly documented,
selectable GitHub Copilot CLI and Copilot app models. Each `models/<model>/`
folder contains an original short digest and source provenance with a direct
publisher document when one exists. Availability evidence comes from
[GitHub's supported-model tables](https://docs.github.com/en/copilot/reference/ai-models/supported-models);
app picker observations are separate from GitHub.com and app Auto selection.

Publisher PDFs and their full text are **linked, not redistributed**: this
repository's MIT license does not license third-party system cards.
See the [rights review](models/RIGHTS.md) and [local-only download and
extraction instructions](models/README.md).
